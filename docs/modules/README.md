# Module Intelligence

One blueprint per module: business purpose, problems solved, users,
integrations, entities, APIs, widgets, KPIs, permissions, navigation,
relationships, and AI opportunities. These documents are the contract for what
gets built — implementation follows the blueprint, and blueprint changes are
reviewed like code.
