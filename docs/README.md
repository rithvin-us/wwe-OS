# Documentation

| Folder           | Content                                                                                       |
| ---------------- | --------------------------------------------------------------------------------------------- |
| `architecture/`  | System design: boundaries, diagrams, tenancy, eventing                                        |
| `api/`           | API conventions and reference                                                                 |
| `deployment/`    | Deploy guides per environment/provider                                                        |
| `development/`   | Developer guides — start with `onboarding.md`                                                 |
| `roadmap/`       | Module roadmap and milestones                                                                 |
| `adr/`           | Architecture Decision Records (template: `0000-template.md`)                                  |
| `meeting-notes/` | Decisions and discussion notes                                                                |
| `design/`        | **Design Bible** — the law for every UI change                                                |
| `modules/`       | Module intelligence blueprints, one per module                                                |
| `specs/`         | Per-module engineering specs (schema, API, events, testing)                                   |
| `services/`      | Docs for standalone deployment-isolated services (`services/*`)                               |
| `reference/`     | Standalone reference material (GPT context blobs, walkthrough, web design tokens/product doc) |

`CHANGELOG.md` lives at `docs/CHANGELOG.md`. `SECURITY.md` stays at the repo
root — GitHub only surfaces the Security tab from a root or `.github/` file.
